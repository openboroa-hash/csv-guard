# Landing gratuita de CSV Guard

Artefacto local no publicado. Página estática autocontenida para descarga pública directa, sin formulario, lista de espera, scripts, imágenes, analítica ni recursos remotos. Solo enlaza el paquete, su manifiesto, documentos locales y el correo comercial autorizado.

## Estructura de despliegue

El sitio preparado incluye:

- `launch/downloads/csv-guard-0.1.0.zip`
- `launch/downloads/csv-guard-0.1.0.SHA256SUMS.txt`
- `launch/OFFER.md`
- `launch/FAQ.md`
- `launch/INSTALL.md`

El ZIP y el manifiesto están colocados localmente. Antes de publicar, hay que recalcular/verificar el hash y repetir la descarga desde una sesión anónima en el canal real. No sustituir archivos sin cambiar versión/hash.

## Puerta de publicación

1. Cuenta/canal autorizado y términos aceptados por su titular.
2. Identificar el proveedor real y completar los avisos legalmente exigibles según titular, establecimiento y audiencia; no publicar borradores con campos pendientes.
3. Descargar paquete y manifiesto desde una sesión anónima, verificar integridad y ejecutar el ejemplo sintético.
4. Probar teclado, móvil y enlaces; confirmar que la página no hace solicitudes de terceros propias.
5. Registrar URL, fecha, versión y hash en PROGRESS.md.

No añadir cookies, píxeles, formularios ni scripts remotos sin revisar antes su tratamiento de datos. La publicación inicial es gratuita: sin checkout, donaciones o promesas de soporte.
